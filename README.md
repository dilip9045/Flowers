# 🌸 Living Garden

An interactive, responsive romantic flower experience built with SVG, CSS, and Vanilla JavaScript.

## Features
- **Cinematic Bloom Sequence**: Hero rose with an expanding living meadow of roses, golden sunflowers, tulips, lavender, and daisies.
- **Procedural Growth & Web Audio**: Harmonic chimes, organic stem uncurling, and petal-by-petal opening animations.
- **Interactive Floral Garden**: Touch flowers to trigger petal showers, chimes, and romantic quotes.
- **Theme switcher**: Change between the built-in Midnight, Morning, Vintage, and Enchanted themes while viewing the garden.
- **Photo card**: Open a centered, translucent photo card featuring the image in `public/`.
- **Responsive**: Mobile-first and desktop-optimized layout with adaptive SVG rendering.

## Getting Started
Open `index.html` in any modern web browser or serve locally:
```bash
python3 -m http.server 8085
```
